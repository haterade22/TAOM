### Corrected evidence

- "29 to 33 s on 25 of 25 launches" is **30 of 30** logs (29 to 33 s), plus four older crash bundles at
  33 to 51 s.
- `rgl_log_42764.txt:694-695` (not 694-696; 696 is `MBModuleBase Initialize begin`, harmless).
- **Fix sketch is wrong as written.** Renaming the setting to `EnableNativeToManagedCaptureV2` with
  default false changes nothing: MCM's provider is null during `OnSubModuleLoad` (link 2), so the gate at
  `SubModule.cs:201` always falls through to `?? true`. The same holds for `EnableCrashCapture` at `:195`.
  A working fix changes code, not the MCM default: flip the fallback to `?? false` (or delete the sweep,
  or read the persisted value some other way). The "Persisted MCM defaults" trap does not apply at this
  call site because MCM is not read at all. The MCM hint text (`CrashReportSettings.cs:21,31`, "Installed
  once at launch ... only when this is on") and `crash-report.md:278` ("Disable via MCM") are also false
  for the same reason; the player has no way to turn this cost off today.
- Delta confirmed pre-existing: the patcher came in `7df18ca0` (2026-05-25), an ancestor of June's `141b749`.

### Impact today
