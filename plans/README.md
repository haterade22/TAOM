## How to execute one

- Hand a plan to any agent: *"implement `plans/002-nan-infinity-config-guards.md`"* — or, once the `/improve`
  skill's `execute` path is wired for TAOM, `/improve execute 002` dispatches a cheaper executor in an isolated
  worktree and reviews the diff. Either way the advisor never edits source; merging stays the user's call.
- Each C# plan is TDD-first (failing test before the fix) and ends with `dotnet build … -p:DisableModuleCopy=true`
  + `dotnet test TAOM.Tests -p:DisableModuleCopy=true` as machine-checkable done-criteria. **Never `./build.ps1`**
  from an executor — it deploys into the live game install.
