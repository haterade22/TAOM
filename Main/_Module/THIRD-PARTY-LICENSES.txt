Scene scripts under Main/SceneScripts/ take behavioural inspiration from the
Alliance mod (https://github.com/Byak0/Alliance, GPL v3). They are TAOM original
work produced by a clean-room procedure: Alliance source was read once to extract a
behavioural spec, the spec was committed, and the implementation was written from
the spec. No Alliance source code appears in TAOM. Procedure and per-file mapping:
docs/scene-scripts/ATTRIBUTION.md in the TAOM repository.

----

TAOM.NativeSkinFixes.dll is built by TAOM from the source in this project's
repository. Its native hooks re-implement the behaviour of an earlier community
mod of the same name, read as reference while they were written, and adapted to
this engine version. It links MinHook, above.
