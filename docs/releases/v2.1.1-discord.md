# TAOM v2.1.1

**Hotfix. If you downloaded v2.1.0, replace it: v2.1.0 cannot start a campaign.**

## 💥 What was broken

Starting a new game threw a null-reference error before the map loaded, and depending on where you
looked you saw one of two different errors that appeared to be unrelated.

They were the same bug. The v1.5.0 update made the game read a culture's notable list entry by entry
without checking what it was reading, and TAOM had **explanatory comments sitting in that list**. The
game tried to read a comment as if it were a character and threw.

The knock-on is what made it confusing. That error stops the culture file being read at all, and
Gondor's culture is defined near the bottom of it, so Gondor never got created. The second error was
the game trying to build the kingdom of Gondor with no culture behind it, which looks like a kingdom
problem and is not.

The comments are gone from the list and the explanation moved to the top of the file. **Nothing else
changed**, and no game content was touched: all 24 cultures and every notable, including the new
female entries, are exactly as they were in v2.1.0.

## 🔒 So it cannot happen again

A new automated check refuses any build where a comment sits inside a culture's child list. It was
deliberately tested against the broken file first to confirm it actually catches this, then against
the fixed one.

## ⚠️ Unchanged from v2.1.0

Still requires **Bannerlord v1.5.0** (Steam beta branch), and **War Sails must be off**. See the
v2.1.0 notes for everything in this release; v2.1.1 adds nothing and only fixes the above.
