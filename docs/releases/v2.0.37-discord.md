# TAOM v2.0.37 (tester build)

## ⚠️ Bannerlord v1.5.7

This build is for **Bannerlord v1.5.7** (Steam **beta** branch; the last note said v1.5.6). You must be on the v1.5.7
beta. The v2.0.36 build does not run on v1.5.7: a new campaign stays on the loading screen and never reaches the map.
This v2.0.37 build does not run on v1.5.6.

- **Not yet played on v1.5.7.** The automated checks pass, but nobody had started a campaign with this build on
  v1.5.7 when this note was written. The first thing we need from you: start a new campaign and tell us whether you
  reach the map.
- **Modules:** all four modules (TAOM, TAOM.Dependencies, TAOM_Map and LOTRLOME_Armory) read **v2.0.37**. Install
  them together. TAOM and TAOM_Map must come from the same package: a TAOM with an older TAOM_Map can fail on a new
  campaign.
- **Install into a clean folder.** Remove the old `Modules\TAOM` folder first. This build no longer ships eight screen
  files, and copying the new files over an old install leaves them in place.
- ⚠️ **Saves: start a new campaign.** The map gained realms and settlements since v2.0.36 (Ered Luin, Dorwinion and
  South Rhovanion among them), and its distance cache was rebuilt with them. A v2.0.36 campaign is expected not to
  load (read from the game's code, not confirmed in game; if you try one, report what happens).
- ⚠️ **Two settings start again at their default**, because each is stored under a new name:
  - **Tournament bet cap per round** is now 15,000 (it was 0, which means unlimited). You can raise it to 1,000,000
    or set it back to 0.
  - **"Allow Sauron and the Nazgul"** (Player Switcher) is now on. Turn it off again if you had it off.
- **Co-op:** do not start a co-op session on this build yet. The co-op mod must be rebuilt for v1.5.7 first.

## 🗺️ Bannerlord v1.5.7

- **A new campaign starts again.** Bannerlord v1.5.7 changed how the game asks for a party's size limit. With v2.0.36
  the first patrol that spawned raised an error on every frame, so the loading screen never ended.
- An AI lord who leads an army: the "Last seen leading an army ..." line on his encyclopedia page now comes from the
  base game, in the base game's wording.
- If you do load an older campaign: the first time v1.5.7 loads it, the base game removes dead heroes, and disabled
  heroes of other clans, from party and prisoner lists. That is base-game behaviour, not TAOM's.

## 📦 Also in this build

Everything merged since v2.0.36 is in this build: Fords of War, The Long Defeat, Seat of Seeing, Marshal's Word,
Staged Siege, the new realms on the map, Lothlorien, the dire wolves, the dwarf attacks, the career changes, the
faction screens and many fixes. The notes for each of them follow in an update of this page.
