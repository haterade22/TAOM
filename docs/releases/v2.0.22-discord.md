# TAOM v2.0.22

Point release on top of v2.0.21, fixing two things an independent review pass caught in the new Aura of Dread.

- **Wraiths no longer drain morale during the pre-battle deployment phase.** The order screen counted as part of the battle, so a wraith already in range was wearing your line down while you were still placing formations. Take as long as you like over deployment now.
- **A warm-up guard could silently switch itself off** for the rest of a battle if the engine ever handed the mod a bad frame time, letting the aura start a fraction of a second earlier than intended.

Nothing else changed. If you are already on v2.0.21 this is a small correctness update, not new content.
