# TAOM v2.4.0

**This is the Bannerlord 1.4.8 line.** The version jumps from the public **v2.0.29.5** to **v2.4.0** on purpose: 2.4 marks the 1.4 line and sorts above the old build, so a crash report points at the right code.

Most of this release ports **performance, loading, memory and stability fixes** from the newer TAOM line to 1.4.8. Gameplay content (new troops, kingdoms, features) is not the focus.

Ships with: `TAOM_Map v2.4.0 sha256:6e9d81ad9c79 (49 files), LOTRLOME_Armory v2.4.0 sha256:1c3827bf3679 (464 files)`

## 📦 Install and saves
- **Delete your old `Modules\TAOM` folder before installing.** Eleven screen files that were plain copies of the base game are gone, and an install over the top leaves them in place.
- **TAOM_Map and LOTRLOME_Armory ship as v2.4.0 too.** Their language files now carry the game's own grammar processors for German, French, Italian, Polish, Russian, Spanish and Turkish (and the Armory's English file), so grammar tokens in those languages print again.
- TAOM again **requires its matching TAOM.Dependencies** at load (a mismatched install could break characters into bind pose) · the launcher lists TAOM.Dependencies first · bundled MCM and ButterLib are now builds made for 1.4.6 to 1.4.8 · no more Game Pass folder (Game Pass is not supported)
- **Existing saves should load.** A few fixes show only in a new campaign: Gondor's policy, the lesser Nazgul kits, translated names for the six Umbar clans, culture starter kits.

## 💥 Crashes and hangs
- **Creature mounts:** battles with wargs, war rams, elks, elephants, mumakil, chariots and other creature mounts should no longer crash when a rider or mount dies. The spider anti-crash fix now covers every creature mount; vanilla horses, camels and mules are unchanged.
- **No more endless battle loads:** a failing battle start is logged, shown once and the battle starts · an item naming a missing collision body loads after about **5 seconds** instead of freezing · too many skeletons in one frame no longer freezes the battle · an error in a battle tick no longer freezes it with the audio still playing · background-thread callbacks no longer corrupt state and stall battles
- **Campaign crashes:** talking to the tavern musician (seven towns, among them Dol Guldur, Isengard, Lothlorien and Rivendell) · a lord's child born to a parent loaded without a culture · new game or Gold Rush with bandit clans out of step with the map · siege aftermath menus · supply caravan routes off the land navmesh, plus fixes aimed at crashes reported when ordering supplies or returning to a siege · Custom Battle with Nord, Vakken or Darshi · corrupt War of the Ring momentum data in a save · a new repair step for stale characters
- **Frozen states:** AI map battles stuck at N vs 0 (such as 8000 vs 0) · kingdom votes already decided when they open · taken-over lords like Boromir or Faramir now lead their clan, ending frozen vote windows (older saves repaired at launch) · four rare enlisted cases stuck after a battle · a crash on Send troops while enlisted at high fast-forward · a "Go on your way" exit if service ends while a save loads
- **Patch safety:** one failing patch group now costs only that group, with a notice naming it, instead of skipping every later patch · crash capture wraps **16 engine callbacks instead of 247**, removing a way to freeze the next battle frame · Enable Crash Capture toggles now apply without a restart
- **Better crash reports:** exact TAOM build stamp · game build and every module version · a clean-exit mark · **30 logs kept instead of 10** · the TAOM.Dependencies log is included · only TAOM's own settings are listed · no false stall report when battle setup throws

## 🚀 Performance, loading and memory
- **Module data merges much faster** on campaign loads and Custom Battle: one player's load had spent **27.2 of 70.5 seconds** on this step.
- The **siege-end stutter** (about 170 ms, up to **281 ms** in one frame, any time a settlement changes hands) is gone, and loads skip an unused settlement distance table.
- **Clan, inventory and trade, party and quest screens open faster**, with a switch for each in the new Screen Performance group.
- Campaign map: hidden settlement nameplates no longer update every frame (faster, especially on fast-forward) · after every **20 screens** the map view's GPU memory is freed on return (a short loading screen)
- **Cheat mode** no longer lists every item and troop, which in one player's log froze the game for **31 seconds** and grew memory from 489 to 2,841 MB; "Cheat Mode Lists All Items And Troops" (off) brings the old lists back.
- **Battle corpses** fade after **60 seconds** and are capped at **25** to address reported mid-battle freezes, with sliders in Mod Options and an offer at the main menu to lower your ragdoll and corpse settings.
- **Shaders:** the Pre-compile Shaders walk is back for 1.4.8 and covers every troop · a progress window during shader cache rebuilds, with the game at lower priority so your PC stays usable · a small window during a battle render wait shows how many shaders are compiling
- PCs with about **16 GB** or less at max Texture Quality get one popup suggesting a lower Texture, then Foliage, Quality.
- Smaller files: the UI texture pack drops **39 unused banner sheets (41,529,118 bytes)** with the next published pack · the lords data file is **360 KB** smaller · save loads do a little less work per object
- Less work per tick: career perk and career log lines cut way down · auto-resolved battle logging removed · combat, battle balance and campaign settings read once · plain AI formations skip TAOM's extra work · cheaper creature and warg AI · the service board redraws only on change · cheaper always-on battle diagnostics
- New logs so a stutter leaves a trace: frame times every five seconds · frames of **250 ms** or more · animation clip memory against its **12 MiB** budget · freezes of **10 seconds** or more · where a frozen battle is stuck · where campaign load time goes. Opt-in, off by default: map profiler, tick profiler, load-time stamps, memory dump on freeze, Lost Footing census.

## ⚔️ Battles
- **Cavalry knockdown parity:** orcs and uruks fall like vanilla again, trolls resist strongly, a full-speed horse floors a man from any angle
- **Custom Battle** runs TAOM's combat rules · Mordor, Gondor and Rohan show their lore commanders · formations default to each culture's own troops · trolls kept off banners (cave trolls in battle no longer lift a dropped one either)
- **Aura of Dread** now reaches only enemies within **5 m** and stops at morale 10, so it no longer routs the whole field
- **Smart Cavalry AI** really forms a line, rides through and reforms; a second F3 charges at once; new Max Line-Up Seconds (default 4)
- **Siege Dismount works:** your horse goes to the inventory before you spawn and comes back after
- **Hideout boss fight** is the boss plus a few bodyguards instead of 20 to 40 troops, about 90 at the endgame density cap (Hideout Boss Bodyguards, default 4)
- Battle action bar is now "Show Battle Action Bar", off by default; it no longer grabs the cursor or the 1 to 9 keys
- Dunland's Hunter fights with the archers, Hebog-lûth bows as horse archers · Lindon and Blue Craig raise banners · seven Harad, Rohan and Dunland horse archers draw their bows · refuge defenders' horses share their damage reduction

## 🐺 Creatures and mounts
- **War Ram:** Dwarven cavalry can ride a new mount with its own attack, through a new branch that shows up in volunteer pools
- Warg rages no longer break the warg for the battle: riders get their formation back; rages end after 6 seconds without an attack and always last 2 attacks, so they end sooner · no lost controls when the rage controller is missing · reinforcement riders keep formation · bite clips no longer misfire on cavalry mounts
- Creature knockdowns no longer read "Crushed through!" in the combat log

## 🏹 Troops and lords
- **Armour rebalanced** to a per-kingdom ceiling, Erebor at the top · an upgrade never leaves a troop in weaker armour · **every troop bow and crossbow re-ranked** by tier and kingdom (Dol Guldur down, the Moon Guard up)
- Troop gear matches the current Armory, so archers keep their bows · Gondor's empty slots filled, with new armour, shields, crossbows and bastard swords (two troops renamed) · the Uruk-Hai Champion and Berserker wear their skirt
- Party size: level **41+** elites count **3** · Lindon matches Rivendell (party space, **40% less death**) · garrisons and patrols pay no troop-weight penalty · a rounding bug that cost a slot is fixed
- Gondor elites 41+ cost Castar · Black Numenorean upkeep rescaled, then halved again · only the two Numenorean houses, Sauron and the vassal reward field them
- Lords made during a campaign wear their culture's gear · the three lesser Nazgul always wear their kit · Faramir and Sauron lead their own party mix · every ruler has a proper title (no more "Emperor of Calradia" in Dunland) · 40 wanderers tell their own backstories · veteran militia sit 15 above basic militia on every skill
- AI lords skip recruiting trips the Free and Evil rule would refuse, and empty castles · "AI Recruits From Castles" off now covers entry recruits · orcs and goblins no longer overbreed · no alignment desertion while in a battle

## 🛡️ Enlistment
- **You fight your commander's battles:** "Leave it to the others" is closed in most cases and pays no renown · Leave and Abandon hidden · you join the fight when a lord relieves a raided village · you stay out of his own raids
- **No private wars:** joining his battle against a new enemy takes on his war and discharge ends it · a vassal no longer drags his kingdom into war
- Grace state: no promotion, board shows 0 pay · merit counts only your hero's kills · siege duties for defenders · no wage lost to debt · survival rolls with your own Medicine · no Order of Battle screen · the quartermaster gives the real reason · each duty has its own text · no casualties before you see a raid defence · state cleared on every load and new game · new console commands to check state and rescue a stuck player

## 📜 Careers
- Tier locks and one keystone per tier work (choices left over from another career are refunded) · goblin, Misty Mountains, Blue Craig, Lindon, Shaghana and Abanissa battle abilities apply
- Mount charge picks and the Cavalry buff reach your horse · Blunt and Cut resist only their type · Ammo covers thrown weapons · party size picks apply at once, own party only · the resource gain passive scales every earning · siege and capture credit inside another lord's army · heirs get a fresh career quest
- Active Effects shows the root perk, keystones and mount health percentages · 18 empty icons filled · tooltips sized properly

## 🗺️ Campaign
- **War of the Ring:** Full War declares Hostile wars for real (old saves repaired on load) · no instant Free win with no Evil realm · raids score momentum once · the popup shows the lead that decides the war · phase, momentum, resources and hero races no longer leak between campaigns in one session
- Special resources: raids and hideout clears pay once · real spend amounts, upkeep in the tooltip, no "-2147483648 days" · no desertion from merchant-only rows · the Confirm hotkey can't bypass a resource cost
- Messengers no longer move armies or hand over troops · fiefs go to the clans that fought the siege (Absent From Siege Factor, 0.50) · alignment follows the realm a hero serves · wanderers refuse an opposed-alignment player · battlefield promotions reach every race
- Supply order search across every market · fast-forward buttons apply the multiplier · refuge founding and Return to Army no longer strand you · culture starter kits · markets skip not-for-sale gear · tavern ale and stew · seven clan banners fixed · heroes keep their race · Mordor's card states its +20%

## 🖥️ Interface
Settlement nameplates **coloured by relation**, with opacity options and a working distance fade · presets, Unequip All and Quick Actions sells refresh the open inventory · clan colours on portraits and the paper doll · map bar resource counter shows on load and leaves when lost · F6 and Make camp respect map state · encyclopedia resource badges · Send Messenger button styling · troop upgrade pop-up matches 1.4.8 · dwarf portraits and the Load Game rider fixed.

## 🌍 Localisation
**Grammar works again** ("Aragorn's Party", not "Aragorn Party") · **313 strings** no longer show in English · **181 rewordings** use the game's curated translations · a translation run cleared the older backlog in all 12 languages, but many texts new in this release read in English until the next run · quest and Umbar clan name mix-ups fixed · conversation overrides match only their culture or persona again · troop, lord, clan and kingdom names are now translatable (English until the translation run lands)

## ⚙️ Settings
- Most TAOM settings now **apply and save at once** instead of reverting next launch after a cancelled restart prompt · nameplate fade settings honoured · removed: Sell Damaged/Low Value Equipped, Log Auto-Resolved Battles, Log Troop Census · corrected hints
- Renamed so new defaults reach everyone, **so a value you chose must be set again:** Auto-Knockdown Weight Ratio (6), Dread Radius (5 m), Show Battle Action Bar (off), Enable Enlistment Trace (off), the siege fief player exemption, the shader scene-pass setting (off), and thirteen more (WotR Phase 1/2 on days 30/44, Initial Hideouts Per Faction 7, Max Parties Per Hideout Cap 6, Merit To Promote 32, Offers Per Battle 2, Smart Cavalry AI and Formation Presets off, AI Party Size neutral)
- ⚠️ **Bandit hideouts:** new defaults are **7 per faction** (was 14) and **up to 6 parties per hideout** (was 3), and they reach existing settings files. If you had set your own values, set them again. The hideout count applies when a new map is generated; hideouts already in a save stay.
