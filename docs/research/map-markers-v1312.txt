# TaleWorlds Map Marker System Research (v1.3.12)

## Executive Summary

Bannerlord v1.3.12 provides a robust map marker/waypoint system that is the correct way to add visible pins to the campaign map. Markers are managed by Campaign.Current.MapMarkerManager and registered with VisualTrackerManager for rendering.

Minimum code to create a visible settlement marker:

var marker = Campaign.Current.MapMarkerManager.CreateMapMarker(
    banner: settlement.Banner,           // Banner to display
    name: settlement.Name,               // Tooltip text
    position: settlement.GetPosition(),  // Position on map (Vec3)
    isVisibleOnMap: true,               // Show on campaign map
    questId: "my_quest_id"              // Unique identifier
);

To remove:

Campaign.Current.MapMarkerManager.RemoveMapMarker(marker);
// OR bulk remove by quest ID:
Campaign.Current.MapMarkerManager.RemoveAllMapMarkersByQuestId("my_quest_id");

### 3. VisualTrackerManager

Namespace: TaleWorlds.CampaignSystem
Access: Campaign.Current.VisualTrackerManager (public property)

Purpose: Tracks all ITrackableCampaignObject instances for rendering. You do NOT call this directly — MapMarkerManager handles registration automatically.

Key Methods:

public void RegisterObject(ITrackableCampaignObject trackableObject)
public void RemoveTrackedObject(ITrackableBase trackableObject, bool forceRemove = false)
public bool CheckTracked(ITrackableBase trackableObject)
public int TrackedObjectsVersion { get; }

---

### 4. Settlement Class

Namespace: TaleWorlds.CampaignSystem.Settlements

Key Fact: Settlement implements ITrackableCampaignObject directly, but is NOT used as a MapMarker itself.

Relevant Methods:

public Vec3 GetPosition()
public override TextObject GetName()
public Banner Banner { get; }
public PartyBase Party { get; }
public SiegeEvent SiegeEvent { get; set; }

Note: You pass settlement.Position.AsVec3() (or settlement.GetPosition()) to CreateMapMarker(), not the settlement itself.

## COMPLETE WORKING EXAMPLE

using TaleWorlds.CampaignSystem;
using TaleWorlds.CampaignSystem.Map;
using TaleWorlds.CampaignSystem.Settlements;
using TaleWorlds.Core;
using TaleWorlds.Library;
using TaleWorlds.Localization;

// In a Campaign Behavior or service:

public void CreateSiegeMarker(Settlement settlement)
{
    if (settlement == null || Campaign.Current == null)
        return;

    var banner = settlement.Banner;
    var markerName = new TextObject("Siege: " + settlement.Name.ToString());
    var position = settlement.GetPosition();

    var marker = Campaign.Current.MapMarkerManager.CreateMapMarker(
        banner: banner,
        name: markerName,
        position: position,
        isVisibleOnMap: true,
        questId: "siege_" + settlement.StringId
    );

    // Optional: Store marker for later removal
    _activeMarkers[settlement.StringId] = marker;
}

public void RemoveSiegeMarker(Settlement settlement)
{
    if (settlement == null || Campaign.Current == null)
        return;

    Campaign.Current.MapMarkerManager.RemoveAllMapMarkersByQuestId(
        "siege_" + settlement.StringId
    );
    
    _activeMarkers.Remove(settlement.StringId);
}

// Siege end handler:
public void OnSiegeEnded(SiegeEvent siegeEvent)
{
    if (siegeEvent?.BesiegedSettlement != null)
    {
        RemoveSiegeMarker(siegeEvent.BesiegedSettlement);
    }
}

## KEY DESIGN DECISIONS

1. Why MapMarker vs. tracking Settlement directly?

- Settlement is an ITrackableCampaignObject but is already tracked for party management.
- MapMarker is a lightweight overlay specifically for quest objectives and notifications.
- Using markers keeps concerns separated: settlements are persistent, markers are ephemeral.
- You can display multiple markers over the same settlement.

2. Why Banner + Name + Position?

- Banner: Provides a visual cue (faction color/symbol). Can be null; UI defaults to a generic marker.
- Name: Tooltip text. Use new TextObject() for static strings or localized keys.
- Position: Must be Vec3 (3D world space). Settlement position is always valid.
- QuestId: Links markers for bulk removal. Use a unique string per objective.

3. IsVisibleOnMap flag

- true: marker appears on campaign map
- false: marker is tracked but invisible. Useful for undiscovered waypoints.
- Can be toggled at runtime: marker.IsVisibleOnMap = value

4. Lifecycle hooks

- OnMapMarkerCreated / OnMapMarkerRemoved events fire automatically.
- No need to manually register with VisualTrackerManager.
- Removal with RemoveMapMarker() → unregisters + fires event.

## BANNERLORD v1.3.12 COMPATIBILITY

- MapMarkerManager and VisualTrackerManager are stable public APIs.
- No changes from v1.3.0 to v1.3.12 to this system.
- VisualTrackerManager has late-load callback for save-game migration from v1.2.
- Settlement safely implements ITrackableCampaignObject.

## TL;DR: SIEGE MARKER USE CASE

// Create (when siege starts)
var marker = Campaign.Current.MapMarkerManager.CreateMapMarker(
    settlement.Banner,
    new TextObject("Under Siege: " + settlement.Name),
    settlement.GetPosition(),
    isVisibleOnMap: true,
    questId: "siege_" + settlement.StringId
);

// Remove (when siege ends)
Campaign.Current.MapMarkerManager.RemoveAllMapMarkersByQuestId(
    "siege_" + settlement.StringId
);

That's it. Settlement position is always valid; Banner and Name are never null.
