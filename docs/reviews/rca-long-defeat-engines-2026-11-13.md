# RCA: The Long Defeat engine restore (#1160), 2026-11-13

Findings from the tier 1 review of the engine restore, with why each was missed and what now prevents it. Codex ran at `ultra` (4 MEDIUM, 1 LOW; the prompt is `docs/reviews/codex-prereview-ld-engine-restore-2026-11-13.prompt.md`, and its raw output stays in the ignored `docs/reviews/raw/`), and wave 1 ran the data flow, engine compatibility and tooling lenses. No reviewer reported a CRITICAL or HIGH, so no second wave ran. Every row was re-read against the code or the v1.5.7 decompile before it was fixed. Rows that two or more reviewers reported are merged and name each source.
