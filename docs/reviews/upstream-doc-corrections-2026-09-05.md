# Upstream doc corrections: claims checked against the files and found wrong

Gathered 2026-09-05 while researching the modder handbook (`docs/modding/`). Four independent
critics re-checked the claims the research had collected from TAOM's own documentation against the
shipped files and the v1.4.8 decompile. These are the ones that did not survive.

**The handbook contradicts every row below rather than inheriting it.** The source docs are still
stale, which is what this list is for.

**Each row is a hypothesis, not a verdict.** Re-run the evidence command before editing a doc: a
count measured in September can be stale by the time someone acts on it, which is the same failure
this list documents. Fix a line only when its evidence is a command output or a decompile line you
have reproduced.
