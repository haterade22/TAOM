## Root-cause pattern

Rows 1, 3 and 6 share one habit, the same as in Phase 0: text that was true when it was written (a comment, a hint, a doc sentence) was not read again when later code changed its ground. In row 1 the text was a code comment and the cost was a real defect. Rows 2 and 4 share another: a second caller reached shared state (the console, the HUD) and the state did not say who had put it there.

## Why each reviewer missed these

- **The builder** added each condition around `Step` for its own feature and tested the rule through `Step` alone, so no test ran the tick's branch that skips it. The lesson headings for `localization-ui.md` were listed for this phase, as the Phase 0 RCA asked, and the hint rule was read; the hint was still not read again after Phase 2 changed the pools.
- **Lens 5** and **lens 2** both found row 1, from the callback and from the tick. Lens 5 found rows 2, 6 and 7, lens 2 row 5, lens 7 row 3, and lenses 2, 5 and 7 each found row 4.
- **The convergence pass** found two comments that the fix script had left wrong (a doc comment on the wrong method, a thread contract that did not name the new cross-thread read). Both are corrected.

## Feedback to codify

At a phase boundary, before the review: grep the feature's hints and doc for absolute words, and for each accumulator list the states in which its consumer does not run. Both are in the lessons added with this file.
