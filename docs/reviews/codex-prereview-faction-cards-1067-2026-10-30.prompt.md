## The change

Uncommitted in the working tree of `E:\repos\TAOM` (`git diff` against HEAD `3d446ac66`). A player reported that named cards on the faction screen (`docs/features/faction-ui.md`, "Taking over a hero") start a new tier 0 clan instead of the character on the card. Three changes:

- **A. Dark lords on by default.** `Main/Features/TaomSettings.cs` (the hunk near line 1904): MCM property `PlayerSwitcherAllowLoreLockedHeroes` (default false) renamed to `PlayerSwitcherAllowDarkLords` (default true), because MCM loads a saved value by property name. `Main/Features/PlayerSwitcher/Domain/PlayerSwitchPolicy.cs` (`Default` now allows them) and `PlayerSwitchPolicyProvider.cs`. Sauron `lord_1_17`, the Witch-king `lord_1_15`, the Nazgul card `lord_1_155` and Khamul `lord_1_48` are now taken over by default, from the faction screen and from Player Switcher's face-generator panel.
- **B. Clanless wanderer cards are adopted.** `Main/Features/PlayerSwitcher/HeroPickerService.cs` `FindTakeover` returns a row with `HasClan == false` for a clanless eligible wanderer (Gimli `named_companion_gimli`, Aragorn `named_companion_aragorn`), so the priority 1100 handover (`HeroSwitchService`, `SwitchPlanner`) runs `AdoptIntoPlayerClan`. `Main/Features/FactionUI/Presets/FactionPickService.cs`: for an adoption it removes only the FaceGenerator, Review and Options stages and keeps BannerEditor and ClanNaming; `RestoreStages` now removes every stage after Culture that is still present and re-appends them in engine order; `TrySkipStages` restores first when the new pick needs another set; `StartupClanIsDisposable` is asked only for a takeover.
- **C. Cross-culture takeover.** `Main/Adapters/IHeroPickerAdapter.cs` and `HeroPickerAdapter.cs` gain `CultureOf(heroId)`. `FindTakeover` uses the hero's own culture, so Haldir `lord_M3_3` (clan `clan_mirkwood_3`, Mirkwood) on the Lothlorien screen and Bolg `lord_MM6_5` (Misty Mountains) on the Gundabad screen are taken over. `BuildPickList` (the panel) still requires the screen's culture.
- Tests: `TAOM.Tests/Features/FactionUI/FactionPickServiceTests.cs`, `TAOM.Tests/Features/PlayerSwitcher/HeroPickerServiceTests.cs`, `PlayerSwitchPolicyProviderTests.cs`. Docs: `docs/features/player-switcher.md`, `docs/features/faction-ui.md`.

**Not in scope (another session's uncommitted work, must not be reported as this change's):** `Client/Features/SupplyLines/SupplyRouteVisualService.cs`, `Main/Features/SupplyLines/SupplyCaravanService.cs`, `Main/Features/AlignmentDesertion/Hooks/AlignmentDesertionBehavior.cs` and its test, `docs/features/supply-lines.md`, `docs/features/alignment-desertion.md`, `TAOM.Tests/Features/SupplyLines/SupplyNativeQueryTests.cs`.
