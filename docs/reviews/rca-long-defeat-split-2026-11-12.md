# RCA: The Long Defeat opening split (#1128), 2026-11-12

Findings from the tier 1 review of the opening split, with why each was missed and what now prevents it. Wave 1 ran the data flow, engine compatibility and tooling lenses; the tooling lens's HIGH called a second wave of the standards, efficiency, completeness and design lenses. Codex did not run (out of usage). Every row was re-read against the code or the v1.5.7 decompile before it was fixed.
