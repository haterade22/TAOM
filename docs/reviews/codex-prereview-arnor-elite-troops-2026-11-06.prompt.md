## Deliberate choices, not defects

- No special resource cost rows for the new Arthedain troops. Mike ruled in #963 that Arthedain troops cost no special resource, and `NoArthedainTroop_CarriesASpecialResourceCost` guards it.
- The four troops are upgrade targets only. They are not in any party template or recruitment pool, so lords do not spawn them. The lord template max sum is unchanged on purpose.
- The Armory has no pike item. The Tharbad Bridge Guard carries the existing heavy spear without a shield and is called a pike guard only in lore.
- The 12 language files hold English text for the four new keys until the maintainer approves a paid translator run.
- A Grey Company troop is not part of this change.
- The unit test BannerlordRefAsmVersion_PinnedGameVersion_IsTheSameGameBuild fails on this machine because the installed game build (125270) differs from the reference package (125053). It is an environment issue.
- Already run and clean: `python tools/validate_moduledata.py` (0 errors), `python tools/data_gates.py` (every gate passes except the loc coverage ratchet, which the baseline update fixes), both generators with `--check`, `python tools/generate_ranged_ladder_items.py --verify`, the whole C# suite apart from the environment test, and `tools/tests` apart from the pin now fixed.
