the early-2026 cherry-pick, the 2026-04-26 ecosystem review and the 2026-05-29 AgentShield port

fixes are in [rca-ecc-adoption-2026-09-29.md](rca-ecc-adoption-2026-09-29.md).

## Security verdict

- **Safe to learn from.** npm lifecycle is only `prepack: npm run build:opencode` (pack time, not
  install). The ported material is classifier logic and prose. A full checkout was read from the
  scratchpad; nothing was installed or run.
- **Install:** not evaluated and not needed. TAOM ports text.
- **Automated vet:** `audit_claude_config.py --root <ecc files> --external` over the 22 extracted
  candidate files (before Step 1's fix it read 5 of them): 0 CRITICAL, 1 HIGH, 9 MED, all benign on
  reading. The HIGH is a comment quoting an attack example inside ECC's own destructive-command
  detector; eight MEDs are its `--no-verify` blocker naming the flag; one is an unpinned `npx -y` in
  ECC's `chrome-devtools` MCP entry, which TAOM does not use.
