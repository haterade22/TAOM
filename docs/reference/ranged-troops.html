What the weapon decides

Speed is the launcher's missile_speed, the one number that sets how far an arrow flies. Reach is that speed run through the engine's drag model on flat ground (gravity 9.806, AirFrictionArrow 0.003, best elevation); the native range function is closed, so read it as relative. Acc is the launcher's accuracy. Bow dmg and Ammo dmg add at launch (Mission.cs:4932), so Total dmg is what the arrow leaves the string with; Shots is the quiver's stack_amount.

What the skill decides

Bow / Xbow are the troop's skills. Spread is the engine's WeaponInaccuracy x1000, (100 - accuracy) x (1 - f x skill) with f 0.0009 for a bow and 0.0005 for a crossbow (DefaultSkillEffects): lower is tighter, and it is the only place the skill meets the weapon. Cadence is AiShootFreq, 0.3 + 0.7 x aiLevel with aiLevel = skill / 300 x 0.96 at Normal combat AI. Opens m, mounted troops only, is the distance a horse archer starts shooting from, reach x (0.3 + 0.4 x aiLevel); foot archers use the full reach. A troop with several battle sets shows its fastest launcher; (+n alt) counts the others.
