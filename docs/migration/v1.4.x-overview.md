## Why this migration matters

Bannerlord 1.4.5 ships **two structural reworks** that hit TAOM's blast radius:
1. **AI Army + Diplomacy reworks** (v1.4.0 base game) — touches `TaomArmyManagementModel`, `TaomAllianceModel`, `TaomDiplomacyModel`, `TaomKingdomDecisionPermissionModel`, `TaomTargetScoreModel`, `TaomBattleRewardModel`.
2. **Equipment system overhaul** (v1.4.3 base game) — `EquipmentFlags` enum simplified, `civilian="true"` deprecated, `EquipmentSelectionModel` return type changed. **3,372 references to `civilian="true"` across 51 TAOM XML files require mechanical migration.**

Plus a third "silent" risk:
3. **`OnRulingClanChanged` parameter semantic flip** — the `Clan` argument used to mean "new ruler"; it now means "old ruler". TAOM doesn't subscribe directly, but `Patch24_BannerDriftGuard` and `Patch12_WarOfTheRing` operate in adjacent territory and must be re-audited.

The user-facing player base will be forced onto 1.4.5 once Steam locks the version; TAOM cannot stay on 1.3.15 indefinitely without losing players.
