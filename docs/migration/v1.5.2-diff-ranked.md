# v1.4.8 to v1.5.2: the bound surface, ranked at the member level

Companion to [v1.5.2-impact.md](v1.5.2-impact.md). Every assembly moved at v1.5.0, so the
file-level diff that ranked v1.4.8 (8 of 56 assemblies) is worthless here. This ranks the members
TAOM binds: every Harmony patch target, every GameModel base method TAOM overrides, every
reflection site and every XML loader (`Deserialize`) whose input TAOM authors. Bodies were
extracted from `E:\Decompiled_Bannerlord\_shipping_build_v1.4.8` / `_modules_build_v1.4.8` and the
regenerated v1.5.2 dumps, diffed per member, and every CHANGED row went to a review agent with the
diff, the TAOM override or patch, and one question: does TAOM re-implement a term that moved.

## The engine themes behind most rows

- **`BattleEnvironment`.** `PerkHelper.AddPerkBonusForParty/ForCharacter/ForTown` gained an
  explicit environment (`Any`/`Land`/`Naval`) and the scattered `!IsCurrentlyAtSea` guards moved
  into per-perk `EffectEnvironment` metadata (`All`, `LandOnly`, `NavalOnly`, `NavalReduced`, the
  last halving the bonus at sea). Most `DefaultXxxModel` bodies changed only in this shape.
- **Personality trait effects.** `TraitEffectHelper.ApplyTraitEffect` and
  `DefaultPersonalityTraitEffects` are new: valour battle renown, generosity morale and upkeep,
  valour loss-morale resistance, honour recruit-penalty reduction, all applied inside the base
  models.
- **Perk helpers own the `HasPerk`/`HasFeat` checks.** Inline `if (hero.GetPerkValue(perk))
  AddFactor(...)` blocks became `PerkHelper.AddPerkBonusFor*` one-liners; `FeatHelper.ApplyCultureFeat`
  does the same for feats. `AddPerkBonusForTown` now requires the governor to be resident.
- **New starting options.** `IsRecruitmentRateModifierEnabled` (volunteer production x0.1),
  `IsIncreasedGlobalMovementSpeedEnabled` (+25% party speed), on top of v1.5.0's
  `IsHighRebellionEnabled`.
- **Constants.** Forest party-speed penalty -30% to -20%, snow -10% to -12.5%; the
  `DefaultTargetScoreCalculatingModel` 1.2x bonus for a party whose `Objective` matches the mission
  type is gone.

## How to redo this on the next bump

`.claude/skills/engine-bump/SKILL.md` Phase 3 now carries the step. The tool is forty lines:
enumerate the bound surface from the API snapshot plus the loaders, locate each member's body in
both single-file dumps by signature, diff, classify SAME / CHANGED / MISSING, and hand the CHANGED
rows to review agents in batches with the diff and the TAOM side. Rank full-replacement overrides
first: they are the only rows that can drift silently.
