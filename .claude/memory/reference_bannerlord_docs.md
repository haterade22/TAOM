- **Bannerlord Mod Docs:** moddocs.bannerlord.com — official modding documentation (WebFetch allowed)
- **Decompilation:** Use `ilspycmd` against DLLs in `%BANNERLORD_GAME_DIR%\bin\Win64_Shipping_Client\` for engine internals
- **Key DLLs:** TaleWorlds.CampaignSystem.dll (campaign logic), TaleWorlds.CampaignSystem.ViewModelCollection.dll (UI), TaleWorlds.Core.dll (core types), TaleWorlds.MountAndBlade.dll (battles)
- **Vanilla data:** SandBoxCore/ModuleData is authoritative for XML structure
- **LOTRAOM assets:** E:\LOTRAOMAssets\ contains reference data from the original LOTRAOM mod
